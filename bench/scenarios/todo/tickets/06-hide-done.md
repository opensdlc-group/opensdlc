# Hide finished todos

Once I've ticked something off I don't want to see it in my list any more. It gets in the way of what's left to do.

- Finished todos should drop out of the list as soon as they're done.
- At the end of each day I go back through the list to see everything I got through, so finished todos need to stay in it.
- Adding, ticking off and removing todos should work as they do now.
