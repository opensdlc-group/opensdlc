# Keep a list of things to do

I keep forgetting small jobs. I want to write a todo down in one step and see everything I have written down, in the order I added it.

- A todo has a title. Spaces at either end don't count. A title can't be empty or longer than 200 characters; tell me when it is and save nothing.
- Every todo gets an id I can use to refer to it later. Ids never change and are never reused, even after a todo is gone.
- A new todo is not done.
